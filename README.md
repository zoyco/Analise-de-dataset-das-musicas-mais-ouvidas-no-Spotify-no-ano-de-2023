# Análise Exploratória de Dados das musicas mais escutadas no Spotify em 2023

## Objetivo
Este projeto tem como objetivo realizar uma análise exploratória de um dataset ddas musicas mais escutadas no Spotify no ano de 2023, identificando correlações e procurando entender o algoritmo usado na medição de categorias específicas 

## Tecnologias Utilizadas
R (tidyverse, GGally, visdat, dplyr)

## Principais Resultados e Insights
Foi possível realizar afirmações com grandes níveis de certeza sobre as categorias quantitativas “danceability_.” , “valence_.” e “energy_.”, concluindo assim o objetivo do trabalho

## Como visualizar o projeto
O código completo com a limpeza de dados e geração dos gráficos está no arquivo `Projeto_Computacional_AED.ipynb`. O relatório final consolidado encontra-se no arquivo `Zico Bettencourt de Faria Costa - Projeto computacional.pdf`.
